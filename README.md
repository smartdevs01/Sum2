\# Sum2 – Java Addition Application



\## Overview



\*\*Sum2\*\* is a simple Java application developed to demonstrate basic programming concepts and arithmetic operations. The application performs the addition of two numbers and displays the result.



This project is part of my journey as a Java developer and aspiring software engineer.



\## Features



\- Accepts two numbers as input.

\- Performs addition.

\- Displays the calculated result.

\- Demonstrates fundamental Java programming concepts.



\## Technologies Used



\- \*\*Programming Language:\*\* Java

\- \*\*Build Tool:\*\* Apache Maven

\- \*\*IDE:\*\* Apache NetBeans

\## Getting Started



\### Requirements



\- Java Development Kit (JDK)

\- Apache NetBeans IDE

\- Apache Maven



\### Running the Application



1\. Clone or download this repository.

2\. Open Apache NetBeans.

3\. Select \*\*File → Open Project\*\*.

4\. Locate and open the Sum2 project folder.

5\. Run the project.
